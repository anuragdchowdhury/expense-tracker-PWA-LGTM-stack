1. SQLite Database Schema & ER Diagram

Persistence is defined in backend/models.py using SQLAlchemy 2 declarative mappings. On every engine connection, _set_sqlite_pragmas runs PRAGMA journal_mode=WAL; for concurrent non-blocking reads during API writes and PRAGMA foreign_keys=ON; to enforce ON DELETE CASCADE referential integrity.

Supported expense categories are enforced via CategoryEnum on both backend validation and frontend selectors:

Food, Transport, Utilities, Entertainment, Health, Shopping, Others.

2. FastAPI Endpoints & Validation Contracts

Routes are mounted under api_router = APIRouter(prefix="/api"). Health checks exist at both /health and /api/health and are excluded from OpenTelemetry tracing spans via excluded_urls="health,/api/health".

Method & Path Input / Query Contract Response & Behavior
GET /api/dashboard ?month=1..12&year=2000..2100&today=YYYY-MM-DD Returns monthly budget status, currency ("INR"), category sums, daily/cumulative array, Mon–Sun weekly array, and sorted expenses.
POST /api/expenses amount (> 0, ≤ 100M, 2dp), category, date, description, optional client_id Returns 201 Created. If client_id already exists for user, returns existing expense idempotently without incrementing metrics twice.
DELETE /api/expenses/{id} Path integer expense_id Deletes user-owned row and returns {"deleted": true, "id": ...}, or 404 if missing.
POST /api/budget amount (> 0, ≤ 100M), optional month, year Upserts row keyed by (user_id, month, year), increments money_tracker_budget_updated counter, returns BudgetOut.
GET /api/categories None Returns ordered CATEGORIES tuple for dropdown synchronization.

3. Dashboard Trend & Category Aggregation Logic

Identical aggregation algorithms run on the backend (backend/main.py) and inside the browser fallback builder (buildOfflineDashboard in offlineStore.js) so charts never flicker or diverge when transitioning offline:

Monthly Category Breakdown

Groups expenses matching YYYY-MM- by category, summing floats rounded to 2 decimal places and sorting descending by total spend for the Recharts donut visualization and percentage share list.

Daily & Cumulative Series

Iterates days 1..daysInMonth via calendar.monthrange (server) or PlainYearMonth.daysInMonth (client), emitting both single-day spend and running cumulative spend per date.

Weekly Window (Mon–Sun)

For the active current month, computes Monday of the current week using ref_today.weekday() (or Temporal dayOfWeek - 1). For historical months, displays the trailing 7 days of that month so past views remain meaningful.

Location-Agnostic Today Param

Frontend supplies the user's local calendar date (Temporal.Now.plainDateISO().toString()) in ?today= so weekly boundary alignment matches the device timezone rather than container UTC.

4. Frontend Modules (INR Currency, Temporal & Native Dialogs)

currency.js — INR Default & Locale

Defaults to DEFAULT_CURRENCY = 'INR' with en-IN formatting (₹25,000.00, compact axis ticks ₹25,000). Persists user selection (INR, USD, EUR, GBP) in localStorage['mt_currency_code'] via Settings.

temporal.js — Safe Calendar Formatting

Conditionally loads temporal-polyfill only when native globalThis.Temporal is absent. Formats month labels via ym.toPlainDate({ day: 1 }).toLocaleString(...) to avoid native Chrome RangeError: Mismatched calendars between iso8601 and gregory.

validation.js — Interaction-First Errors

Prefers native :user-invalid CSS pseudo-class synced to aria-invalid, with a WeakMap dirty/blurred fallback so required field errors only display after user interaction.

AddExpenseDialog.jsx — Native Modal

Uses semantic <dialog closedby="any"> opened via showModal() plus a pointer-bounds fallback for browsers without native light-dismiss, autofocusing the amount field.
